# 📚 Practical Lab: First MapReduce Job (WordCount) with Hadoop, HDFS, and YARN

## Lab Objective
Understand the role of each component in the Hadoop ecosystem through the classic example of word counting (*WordCount*)[cite: 7]:
* **Local Machine (Host)**: Prepare raw data[cite: 7].
* **Docker**: Container hosting the Hadoop environment[cite: 7].
* **HDFS**: Store the file in a distributed manner[cite: 7].
* **YARN**: Allocate containers and coordinate computation[cite: 7].
* **MapReduce**: Execute the filter (`Map`) and aggregation (`Reduce`)[cite: 7].

---

## Step 1: Create the text file on your host machine (Windows / Mac)
Open a standard text editor (Notepad, VS Code, TextEdit) or a local terminal (PowerShell or Mac Terminal)[cite: 7].

Create a file named `input.txt` and paste the following lines into it[cite: 7]:
```plaintext
hadoop hdfs yarn 
mapreduce hadoop hdfs 
yarn hadoop docker docker 
hadoop mapreduce

```

Save the file in an easily accessible folder (for example, on your Desktop or in your user folder).

---

## Step 2: Transfer the file from your machine to the Docker container

Open your terminal (PowerShell on Windows or Terminal on macOS), navigate to the folder containing `input.txt`, and run the following command:

```powershell
docker cp input.txt <NAMENODE_CONTAINER_NAME>:/tmp/input.txt

```

> **Tip**: Replace `<NAMENODE_CONTAINER_NAME>` with the name or ID of your Hadoop container (for example, `namenode` or `hadoop-master`). To find its exact name, type `docker ps`.
> 
> 

Next, connect inside the container:

```powershell
docker exec -it <NAMENODE_CONTAINER_NAME> bash

```

Verify that the file is present in the container's local file system:

```bash
cat /tmp/input.txt

```

---

## Step 3: Load the file from the container into HDFS

The file is currently on the container's local disk. It needs to be transferred to the HDFS distributed file system.

1. Create an input directory in HDFS:


```bash
hdfs dfs -mkdir -p /input

```


2. Copy the file `/tmp/input.txt` to HDFS:


```bash
hdfs dfs -put /tmp/input.txt /input/

```


3. Verify that the file is present in HDFS:


```bash
hdfs dfs -ls /input

```



---

## Step 4: Run the WordCount job via MapReduce and YARN

Hadoop natively includes an example JAR file containing the *WordCount* algorithm.

Run the MapReduce job by specifying the HDFS input directory and output directory:

```bash
hadoop jar /usr/local/hadoop/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.3.6.jar wordcount /input/input.txt /output

```

* `/usr/local/.../hadoop-mapreduce-examples-3.3.6.jar`: The path to the JAR file containing a collection of precompiled example programs provided by Hadoop.


* `wordcount`: The name of the example program to run (which counts the number of occurrences of each word in the text).



> **Behind the scenes:**
> 1. The client contacts the YARN *ResourceManager*.
> 
> 
> 2. YARN allocates a container to start the *ApplicationMaster*.
> 
> 
> 3. The *ApplicationMaster* requests additional containers to execute the `Map` and `Reduce` tasks.
> 
> 
> 4. The final results are written by the reducers directly into the HDFS `/output` directory.
> 
> 
> 
> 

During or right after execution, check the YARN monitoring interface on your host browser at:

👉 **`http://localhost:8088`**

You will see your application transition to the `RUNNING` state and then `FINISHED` (`SUCCEEDED`).

---

## Step 5: View and retrieve the results

1. List the contents of the HDFS output directory generated by the job:


```bash
hdfs dfs -ls /output

```


(You should see two items: `_SUCCESS` (error-free completion indicator) and `part-r-00000` (the file containing the counts)).


2. Display the result directly from HDFS in the console:


```bash
hdfs dfs -cat /output/part-r-00000

```


3. Export the result from HDFS to the container's local disk:


```bash
hdfs dfs -get /output/part-r-00000 /tmp/resultat.txt

```


4. Exit the Docker container:


```bash
exit

```


5. From your host machine terminal (Windows/Mac), download the results file to your computer:


```bash
docker cp <NAMENODE_CONTAINER_NAME>:/tmp/resultat.txt ./resultat.txt

```



The expected content of the results file looks like this:

```plaintext
docker       2
hadoop       4
hdfs         2
mapreduce    2
yarn         2

```
